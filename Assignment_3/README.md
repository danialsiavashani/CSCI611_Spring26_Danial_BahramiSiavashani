# Assignment 3 - Style Transfer

## How to Run
1. Install dependencies: torch, torchvision, PIL, matplotlib, numpy, pandas
2. Place your content and style images in the same folder as the notebook
3. Update the image filenames in the load_image cells
4. Run all cells top to bottom in Jupyter Notebook

- Style_Transfer_Exercise.ipynb — main notebook with all 5 runs and results
- Siavashani_Danial_Assignment3.pdf — report
